خطوات رفع الموقع على Vercel (مفيش Git ولا برمجة مطلوبة):

1) حط ملف الـ APK بتاعك في نفس الفولدر ده، وسمّيه بالظبط: app.apk
   (الروابط الأربعة في index.html بقت بتشاور على "app.apk" جاهزة)

2) روح على: https://vercel.com/drop

3) اسحب الفولدر ده (أو اعمله ZIP واسحب الـZIP) على الصفحة

4) اختار اسم للمشروع واضغط Deploy

5) هتاخد رابط مباشر للموقع شغال فورًا
